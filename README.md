# MiniFlip OS v0.1 test

Prueba mínima para Samsung Galaxy Z Flip5. La app no solicita permisos sensibles.

Objetivo: agregar MiniFlip OS al launcher de Good Lock / MultiStar y verificar que, con el Flip cerrado, pueda abrir WhatsApp, Chrome, YouTube y Ajustes en la pantalla externa.

Estado: proyecto cargado y listo para compilación automática.
